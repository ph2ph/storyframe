# AGENTS.md: storyframe

Выгрузка каталога Storybook для плагина Figma (`app/export`), блок «Варианты» для документации Storybook
(`app/storybook`), адаптер темы MUI (`app/mui`). Пользовательская документация в `README.md`. Плагин Figma
живёт в репозитории `storyframe-plugin` и берёт из этого пакета формат выгрузки, подписи матрицы и писатель
ZIP (точки входа `./format`, `./variants`, `./zip`). Этот файл единственный источник инструкций для агентов.

## Команды

```bash
yarn test            # vitest: сборщик, конвертер DOM (jsdom), адаптер MUI
yarn typecheck       # tsc по пакету
yarn lint            # oxlint
yarn format          # oxfmt; yarn format:check без записи
node bin/storyframe.mjs <команда>   # CLI в папке проекта: export, serve, shots-server, compare, emulate
```

Node 24 (`.nvmrc`): исходники `.ts` выполняются самим Node без сборки. Критерий готовности: `typecheck`,
`lint`, `test`, `format:check`. Изменение формата выгрузки дополнительно проверяется в репозитории плагина
на настоящей выгрузке проекта (`STORYFRAME_KIT=<проект>/storybook-static/figma-data/kit.json yarn test`).

## Устройство

- `bin/storyframe.mjs` содержит CLI; каждая команда это модуль `app/export/*.mjs` с `main(argv, root)`.
- `app/export/paths.mjs`: корень проекта (папка запуска), пути из конфигурации, корень пакета.
- `app/export/config.mjs` и `catalog.mjs`: конфигурация проекта и раскладка каталога по страницам;
  `catalog.mjs` без модулей Node, потому что его читает блок «Варианты» в браузере.
- `app/export/theme.mjs`: загрузка модуля темы проекта через Vite SSR и проверка формата;
  `app/theme.d.mts` описывает формат темы; `tokens.mjs` строит токены выгрузки из темы.
- `app/export/capture/*.ts`: конвертер DOM в дерево слоёв, собирается esbuild и внедряется в страницу
  Storybook; `capture/types.ts` это формат выгрузки, общий со сборщиком и плагином; `schema.mjs` повторяет
  его на valibot.
- `app/export/dataset.mjs`: оркестратор выгрузки, то есть план (`plan.mjs`, `discover.mjs`, `matrix.mjs`),
  съёмка (`capture.mjs`), сведение режимов и привязка к токенам (`merge.mjs`, `colorMatch.mjs`), склейка
  (`dedupe.mjs`), экземпляры (`signatures.mjs`), инварианты (`invariants.mjs`).
- `app/storybook`: блок «Варианты» и страница документации; матрицы строит `app/export/docsMatrix.mjs` по
  тем же правилам, что выгрузка.

## Правила

- Пакет не знает проектов. Знания о конкретном каталоге (страницы, наборы, исключения, имена токенов,
  шрифты) живут в конфигурации и модуле темы проекта; новое различие между проектами это опция
  конфигурации или адаптера, а не литерал в коде. Соглашения о токенах (приоритеты и группы цветов, цвета
  текста, скругление «до круга», подсказка кода) хранятся в полях токенов темы, их заполняет адаптер.
- Формат выгрузки меняется вместе в `capture/types.ts`, `schema.mjs` и в плагине; несовместимое изменение
  поднимает `SCHEMA_VERSION`.
- Идентификаторы только латиницей; кириллица в строках и комментариях.
- Комментарии про нюансы реализации и особенности Storybook и MUI, без пересказа кода.
- В текстах тире редко: там, где можно сказать «это» или перестроить фразу союзом, тире не ставится.
- Тяжёлые прогоны (выгрузка, эмуляция, сверка) держат Chrome и тысячи снимков в памяти: по одному, с
  `--tabs 2` на машине без запаса памяти.
